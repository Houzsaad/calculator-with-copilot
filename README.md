## Calculator

A simple calculator application that performs basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear/reset input
- Responsive interface
- Error handling for invalid operations

## Supported Operations

```bash
Operation	Symbol
Addition	+
Subtraction	-
Multiplication	* or ×
Division	/ or ÷
```

## Getting Started

# Prerequisites

- A modern web browser
- A local server or static-file hosting environment, if required by the app

## Run the Calculator

Open index.html in a browser, or serve the project directory:

```bash
python3 -m http.server 8000
```
