## Calculator

A simple calculator application that performs basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear/reset input
- Responsive interface
- Error handling for invalid operations

## Supported Operations

```bash
Operation	Symbol
Addition	+
Subtraction	-
Multiplication	* or ×
Division	/ or ÷
```

## Getting Started

## Prerequisites

- A modern web browser
- A local server or static-file hosting environment, if required by the app

## Run the Calculator

Open index.html in a browser, or serve the project directory:

```bash
python3 -m http.server 8000
```

Then visit:
```bash
http://localhost:8000
```

## Usage
1 Enter or select a number.
2 Choose an operation.
3 Enter another number.
4 Select = to display the result.
5 Use Clear or C to reset the calculator.
